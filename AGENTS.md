# Портфолио Светланы Шестаченко

Одностраничный сайт-портфолио на обычных HTML/CSS/JS, без фреймворков и сборки.
Опубликован через GitHub Pages: https://loafofeitr.github.io/portfolio/

Главное:
- Владелица — не разработчик. Общайся по-русски и простыми словами, объясняй, почему выбрано то или иное решение.
- Каждый файл отвечает за что-то одно, документация устроена так же: одна тема — один файл.
- Push в `main` только после одобрения владелицы.
- Превью: `python3 tools/dev-server.py . 8080`, затем открыть порт 8080.
