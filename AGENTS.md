# Портфолио Светланы Шестаченко

Одностраничный сайт-портфолио. Опубликован через GitHub Pages:
https://loafofeitr.github.io/portfolio/ (ветка `main`, папка `/`, обновляется примерно через минуту после push).

Владелец — не разработчик: общайся по-русски, простыми словами, объясняй, почему выбрано то или иное решение.

## Файлы

Правило: каждый файл отвечает за что-то одно. Без фреймворков и сборки — обычные файлы.

```
index.html              — только разметка и тексты страницы
css/variables.css       — тема: цвета и шрифт (CSS-переменные)
css/base.css            — общее: сброс отступов, фон body, .container, section, h2, кнопка .btn
css/sections/<блок>.css — стили одного блока вместе с его настройками для телефона (@media)
js/contact-form.js      — поведение формы (показ «Спасибо»)
tools/dev-server.py     — сервер превью с автообновлением (не часть сайта)
AGENTS.md               — этот файл
```

Новый блок страницы = разметка в `index.html` + новый `css/sections/<блок>.css` + `<link>` в `<head>`
(порядок `<link>`: variables → base → блоки сверху вниз). Скрипты блоков — отдельными файлами в `js/`.

## Блоки страницы (сверху вниз)

1. **Навигация** (`nav`, `css/sections/nav.css`) — закреплена сверху, ссылки на разделы.
2. **Шапка** (`header`, `css/sections/hero.css`) — имя, подпись «Начинающий вайбкодер», кнопка «Написать мне» (ведёт к форме).
3. **Обо мне** (`#about`, `css/sections/about.css`) — два абзаца текста.
4. **Проекты** (`#projects`, `css/sections/projects.css`) — три карточки-заглушки (иконка, название, описание).
5. **Контакты** (`#contact`, `css/sections/contact.css`, `js/contact-form.js`) — форма: имя, email, сообщение. После отправки показывает «Спасибо». Сообщения пока **никуда не сохраняются** — это сделаем позже.
6. **Подвал** (`footer`, `css/sections/footer.css`).

## Оформление

Тёмная тема с фиолетово-бирюзовым градиентом. Цвета задаются переменными в `:root` в `css/variables.css`
(`--bg` — фон, `--card`, `--text`, `--muted`, `--accent`, `--accent2`). Фон `#262a4a` выбран как «чуть светлее
прежнего почти чёрного»: полностью светлая тема владельцу не понравилась.

## Как запускать

Превью с автообновлением (страница сама перезагружается через секунду после изменения файла):

```bash
python3 tools/dev-server.py . 8080
```

Затем открой превью на порту 8080 (инструмент `browser_preview`). Готовые решения вроде `livereload`
не работают через прокси превью Devin, поэтому используется свой скрипт: он опрашивает `/__version`.

Можно и без сервера: открыть `index.html` в браузере (файлы `css/` и `js/` должны лежать рядом).

## Как вносим изменения

1. Владелец просит правку в чате и смотрит превью.
2. Когда результат одобрен, коммит и push в `main` — GitHub Pages обновит сайт.
