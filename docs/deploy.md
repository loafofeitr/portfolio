# Публикация

- Сайт публикуется через GitHub Pages: https://loafofeitr.github.io/portfolio/
- Настройки: Settings → Pages → «Deploy from a branch», ветка `main`, папка `/ (root)`.
- После push в `main` сайт обновляется примерно через минуту. Открытую вкладку нужно обновить вручную (F5), автообновление есть только в превью.
- Включить Pages через API у Devin не получится (GitHub отвечает 403): это делает владелица в настройках. Pages уже включены.
