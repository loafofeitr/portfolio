# Структура файлов

Правило: каждый файл отвечает за что-то одно. Никаких фреймворков и сборки, только обычные файлы.

```
index.html              — только разметка и тексты страницы
privacy.html            — отдельная страница «Политика конфиденциальности»
css/variables.css       — тема: цвета и шрифт (CSS-переменные)
css/base.css            — общее: сброс отступов, фон body, .container, section, h2, кнопка .btn
css/sections/<блок>.css — стили одного блока вместе с его настройками для телефона (@media)
js/<поведение>.js       — один скрипт на одно поведение (сейчас: contact-form.js)
apps-script/            — копия скрипта Google, который сохраняет сообщения формы (не часть сайта)
tests/                  — автотесты (см. tests.md), не часть сайта
tools/                  — инструменты для работы, не часть сайта (сейчас: dev-server.py)
docs/                   — документация, одна тема в одном файле
AGENTS.md               — краткое описание проекта и ссылки на docs/
```

## Как добавить новый блок страницы

1. Добавить разметку блока в `index.html` на нужное место.
2. Создать `css/sections/<блок>.css` и положить в него и стили, и `@media` для телефона.
3. Подключить файл через `<link>` в `<head>`. Порядок: `variables` → `base` → блоки в том порядке, в котором они идут на странице.
4. Если блоку нужен скрипт, создать отдельный файл в `js/` и подключить его перед `</body>`.
5. Описать блок в [sections.md](sections.md).
