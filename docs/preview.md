# Превью с автообновлением

```bash
python3 tools/dev-server.py . 8080
```

Затем открой превью на порту 8080 (инструмент `browser_preview`). Страница сама перезагружается примерно через секунду после изменения любого файла.

Как это устроено: `tools/dev-server.py` использует только стандартную библиотеку Python. Он раздаёт файлы и добавляет в HTML маленький скрипт, который раз в секунду спрашивает `/__version` (время последнего изменения файлов). Если ответ изменился, страница перезагружается. Все файлы отдаются с заголовком `Cache-Control: no-store`, иначе браузер может после перезагрузки взять из кэша старые `css/` и `js/`.

Почему не готовое решение: пакет `livereload` и похожие подключаются по WebSocket к жёстко прописанному порту, а через прокси превью Devin это не работает. Обычный HTTP-опрос работает.

Можно и без сервера: открыть `index.html` двойным щелчком (папки `css/` и `js/` должны лежать рядом). Тогда автообновления не будет.
